# Decisions (ADR)

A file `NNNN-slug.md`, the number is the next after the largest. Template:

```md
# Short name of the decision

One to three sentences: the context, what was decided and why.
```

Optional, only if useful: `Status` (proposed | accepted | deprecated | superseded by NNNN),
`Considered options`, `Consequences`.

Record a decision only when all three are true:
1. it is hard to undo;
2. without the context it will surprise a reader;
3. there was a real choice between options.
